# Tessera 通信协议

本目录是 PC、Pi 和 Arduino 协议的统一入口。当前代码实现的是 v0.1 硬件链路，最终像素帧协议尚未实现。

## 当前 v0.1

### PC ↔ Pi 控制通道

- TCP 端口：`7420`
- 格式：每行一个 JSON 对象（NDJSON）
- 用途：心跳、状态查询、停止、回零和点到点移动
- 只有合法的 `heartbeat` 会续租；连接或租约失效会触发安全停止
- 默认配置 `motion.allow_network_commands=false`，因此 HOME/MOVE 在人工解锁前不会执行

### PC → Pi 诊断光标通道

- UDP 端口：`7421`
- 格式：每个数据报一个 JSON 光标状态
- 只保留最新序号；显式 `visible=false` 或约 250 ms 无新数据会隐藏光标
- 这一语义属于 v0.1 诊断模式，最终版本不会让 Pi 理解“光标”或“拖影”

### Pi ↔ Arduino

- USB 串口：`115200 baud`
- 格式：单行文本命令与事件
- Pi 建立连接后会识别固件、确认机器配置、开启 Arduino 看门狗并请求遥测
- Arduino 独立处理回零、CoreXY 运动、限位、停止和主机失联保护

## 下一版画面通道

下一版由 PC 合成完整画面，再把最终像素帧发送给 Pi。Pi 只负责：

- 接收并重组最新完整帧；
- 丢弃不完整或过期帧；
- 处理面板排列、方向、亮度和故障红色通道屏蔽；
- 在 VSync 时切换画面；
- 长时间没有新帧时清屏。

帧格式、分包头和超时时间应在实现前固定，并在本目录加入可机读的协议版本定义。
