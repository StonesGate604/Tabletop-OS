# CoreXY Arduino 调试程序

已按你确认的 **Arduino UNO R3 + A4988、三个细分跳帽全接（1/16）、暂无限位开关** 配置，用于首次低速运动测试。Shield 按常见 CNC Shield V3 引脚布局处理，仍需核对插槽连接和完整皮带绕法。代码无第三方库依赖，不是完整 GRBL，也不接受 G-code。

## 接线和参数

| 信号 | UNO 引脚 | CNC Shield 插槽 |
|---|---|---|
| 电机 A STEP / DIR | D2 / D5 | X |
| 电机 B STEP / DIR | D3 / D6 | Y |
| 共用使能，低有效 | D8 | EN |
| 可选 X / Y 限位 | D9 / D10 | X / Y END STOP |

这里 A/B 是两个联动电机，不是独立的笛卡尔坐标轴。程序采用 `A=(X+Y)*stepsPerMm`、`B=(X-Y)*stepsPerMm`。Shield 上的 A 插槽与这里“电机 A”的命名无关。Z 和扩展 A 插槽不发送步进信号；D8 是公共使能，会同时使能其他已插入的驱动，调试前断电移除不使用的驱动或负载。

在 `.ino` 顶部修改：

- `STEPS_PER_MM`：电机每圈整步数 × 实际细分 ÷（皮带齿距 mm × 同步轮齿数）。默认仅为示例：200 × 16 ÷ (2 × 20) = 80。软件设置不会改变驱动细分跳帽。
- `INVERT_A/B`：对应电机方向反转；默认均 false。
- `X_MIN/MAX`、`Y_MIN/MAX`：默认手动原点周围 ±50 mm，仅用于调试，必须确保机构实际可达。
- `MAX_SPEED=10` mm/s、`ACCELERATION=30` mm/s²：保守初始值，重负载仍可能需要降低。串口速度接受范围为 0.1–10 mm/s。
- `USE_LIMITS=false`：默认不读取限位。启用时，本示例使用常开触点，一端接对应信号，另一端接 GND，按下变 LOW；不适用于未经调整的常闭或有源传感器。

断电后再插拔驱动、电机及跳帽。核对驱动方向、模块允许的供电电压和电机限流；不能只按 Shield 印刷的电压范围选电源。电机电源接 Shield 的电源端子，USB 用于主控和通信。照片里的金属电源接线端应做好绝缘防护。

## 上传与首次运行

1. Arduino IDE 打开同名文件夹中的 `CoreXY_Controller.ino`，选择实际开发板和端口并上传。上传会替换原固件。
2. 电机未使能时，将滑块缓慢放在行程中间，确保周围有足够空间；不要快速推拉电机。打开串口监视器，波特率 **115200**，行尾选“换行”。
3. 逐条发送，等待上一条返回后再发下一条：

```text
ENABLE
ZERO
JOG 2 0 2
JOG -2 0 2
JOG 0 2 2
JOG 0 -2 2
POS
```

`ZERO` 仅将当前位置定义为 (0,0)，不寻找机械原点。先观察 2 mm 点动方向及距离，确认无误后再扩大行程。若纯 X 指令产生纯 Y 位移，检查电机顺序和方向；若走斜线、卡顿或一个电机不转，先排查接线、绕带及驱动，不能靠增大速度解决。仅凭照片不能保证这组 CoreXY 符号约定与实物一致。

确认后可逐条走一个 20 mm 正方形：

```text
MOVE 20 0 5
MOVE 20 20 5
MOVE 0 20 5
MOVE 0 0 5
```

## 串口协议及限制

| 指令（大写） | 含义 |
|---|---|
| `ENABLE` | 使能电机 |
| `ZERO` | 使能后将当前位置设为零 |
| `MOVE x y speed` | 绝对位置，mm；速度 mm/s |
| `JOG dx dy speed` | 相对移动，mm；速度 mm/s |
| `POS` | 输出由脉冲计数推算的位置和状态 |
| `DISABLE` | 释放电机并使原点失效 |
| `!` | 运动中立即停止发脉冲、释放电机、使原点失效 |

每次只发送一条，等 `OK MOVE` 和位置输出完成再发送下一条。运动中除 `!` 外的输入会丢弃，不排队；`!` 无需等待行尾，但停止后请发送一次换行清除残余输入，再重新 `ENABLE`、确认位置并 `ZERO`。停止是突然停止，可能滑行或失步，不能替代切断电机电源的硬件急停。

可选限位触发后同样停止并释放电机，不能在开关仍触发时使能；断开电机电源后缓慢移离开关，重新上电设零。本版不包含自动回零。软限位依赖正确手动设零和无失步运行，不能识别碰撞。位置是开环估计，没有编码器反馈，掉电或释放电机后需要重新设零。

采用同步 DDA 插补及近似梯形/三角形加减速，每段从静止起停，无连续路径前瞻。软件轮询产生脉冲，执行开销会使实际速度低于指令值，不用于高精度高速加工。更改参数应保持合理范围，默认假定两电机具有相同传动比及细分。
