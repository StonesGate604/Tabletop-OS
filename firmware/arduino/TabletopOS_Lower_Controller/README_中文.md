# Tabletop OS Arduino 正式下位机固件

本目录是通过单项硬件测试之后使用的正式固件。它不会替换或修改 `Integrated_Hardware_Test`，需要回查单个部件时仍可重新上传测试程序。

## 上传前必须完成的配置

打开 `TabletopOS_Lower_Controller.ino`，检查顶部的 **MACHINE CONFIGURATION**：

1. `INVERT_A`、`INVERT_B`：保持驱动电气方向；当前正式固件使用 `X_AXIS_SIGN=1`、`Y_AXIS_SIGN=1`，并配合两个方向均为 `-1` 的回零方向，使 X/Y 分别向左、向下寻找起点限位。
2. `SWITCH_NORMALLY_CLOSED`：目前默认 `false`，对应 COM + NO。
3. `X_HOME_DIRECTION`、`Y_HOME_DIRECTION`：当前均为 `-1`，对应两个限位都位于起点（最小端）。横轴运动学反转不会改变左侧起点仍为 X=0。
4. `X_TRAVEL_MM=298`（宽度，`344−46`）、`Y_TRAVEL_MM=466`（长度，`514−48`），减数为移动滑台（carriage）的尺寸，已按 2026-10-26 重新测量结果填写。
5. 当前两个 A4988 驱动插槽下的三个细分跳帽均已安装，`MICROSTEPS=16`。按 200 整步/圈、GT2 皮带和 16 齿同步轮计算，正式固件使用 `STEPS_PER_MM=100`。如果以后改变跳帽、同步轮或传动结构，必须同步修改该参数并重新实测距离。
6. 当前升降机构于 2026-10-26 实测：最高吸附角度 `SERVO_ENGAGE_ANGLE=81`，最低释放角度 `SERVO_RELEASE_ANGLE=118`。固件只接受这个闭区间内的舵机命令；更换舵机或连杆后必须重新标定。
7. `MACHINE_CONFIG_CONFIRMED` 已设为 `true`；若以后改动机械结构，应先改回 `false`。

配置未确认时，固件仍可上传、读取 `STATUS`/`CONFIG` 和控制舵机，但会用 `ERROR CONFIG_NOT_CONFIRMED` 拒绝 `HOME`、`MOVE_TO` 和 `SET_TARGET`。这是有意的安全锁，不应直接删除。当前配置已经根据 298 mm × 466 mm 行程和起点限位启用。

当前正式固件参数为：任务移动软件上限 50 mm/s、连续跟随速度 20 mm/s、加速度 60 mm/s²、最大 8000 步进事件/秒；快速/慢速回零分别为 8 mm/s 和 2 mm/s。软限位在机械两端各保留 2 mm。50 mm/s 尚未完成带负载实测，不是已确认的安全工作速度；首次上机必须从低速、小范围、空载测试开始，并按 15/20/30/40/50 mm/s 分级验证。

## 核心行为

- 上电：步进驱动禁用、舵机信号关闭，状态为 `UNREFERENCED`。
- `HOME`：自动使能电机，依次对 X、Y 执行“快找—退回—慢找—退回”，完成后进入 `IDLE`。
- 当前机构为舵机升降永磁铁：81 度是最高吸附位置，118 度是最低释放位置。上位机应先发送释放角度 118，等待稳定再 HOME。HOME 保持已有舵机目标；Pi 每 2 秒刷新以避免 10 秒信号超时。仿真仍使用虚拟角度 60/120，不能发送给实物。
- 快速寻找限位允许比标称行程多走 80 mm 的脉冲预算，用于覆盖当前传动参数的小幅误差；限位释放和最终退回仍保持独立的 20 mm 安全上限。
- `MOVE_TO`：执行一个带编号的点到点任务，完成后返回 `COMPLETED <id>`。
- `SET_TARGET`：进入连续跟随模式。更大的序号覆盖旧目标，旧序号不会倒退执行。
- `STOP`：按当前速度和加速度进行软件减速停止，尽量保留坐标参考。
- `!`：立即禁用电机、关闭舵机信号并进入 `ERROR`；位置参考作废。
- 正常运动中触发任一硬限位：立即进入 `ERROR`、禁用电机并作废位置参考。
- 连续跟随 500 ms 没收到新目标：减速停止并退出跟随模式。
- 舵机命令 10 秒未刷新：停止舵机控制脉冲，但不会切断舵机电源。
- 周期 `STATE` 默认关闭，避免刷屏。发送 `TELEMETRY ON` 后每 100 ms 输出一次完整快照，发送 `TELEMETRY OFF` 停止；`STATUS` 始终可以单次查询。

## 串口设置

- 波特率：115200
- 数据格式：ASCII 单行命令，以换行结束
- 命令区分大小写，使用大写
- 除紧急字符 `!` 外，所有命令都应发送完整一行

## 上位机发送的命令

| 命令 | 含义 |
|---|---|
| `PING` | 连通检查，返回 `PONG 1` |
| `IDENTIFY` | 返回 `READY TABLETOP_OS_LOWER 1` |
| `CONFIG` | 输出当前关键机械配置 |
| `STATUS` | 立即输出 `STATE` 和 `IO` |
| `TELEMETRY ON` / `TELEMETRY OFF` | 开启 / 关闭周期状态；上电默认关闭 |
| `WATCHDOG ON` / `WATCHDOG OFF` | 开关 1500 ms 主机失联制动；上电默认关闭，Pi 自动开启 |
| `ENABLE` | 使能步进驱动；不会建立坐标参考 |
| `HOME` | 自动回零；配置确认后才能执行 |
| `MOVE_TO id x y speed` | 编号任务，坐标 mm，速度 mm/s |
| `SET_TARGET seq x y` | 连续跟随目标；只接受更大的序号 |
| `STOP` | 受控减速停止 |
| `!` | 无需换行的立即停止；坐标参考作废 |
| `SERVO angle` | 发送舵机目标；当前机构仅接受已标定的 81–118 度安全范围 |
| `SERVO_OFF` | 停止舵机控制脉冲 |
| `DISABLE` | 立即释放步进电机并清除坐标参考 |
| `CLEAR_ERROR` | 清除错误状态；之后仍必须重新 `HOME` |

`MOVE_TO` 的 `id` 必须大于此前接受过的任务编号。任务执行时重复发送同一个活动编号只会再次收到 `ACK`，不会重复启动；旧编号返回 `ERROR STALE_ID`。

`CONFIG` 会同时报告 `MAX_SPEED=50.00` 和 `MAX_STEP_RATE=8000`，可用于确认开发板已经运行新版固件；这些值是软件上限，不表示实物已经通过该速度测试。

比较使用32位差值，支持有限窗口回绕。CONFIG 现在含 `LAST_TASK_ID`，Pi 据此分配下一个编号并跳过0，缺此字段的旧固件不能执行新版 Pi 的 MOVE。uint32 解析显式拒绝溢出。

`SET_TARGET` 适用于鼠标或手部跟随。上位机应以稳定频率发送最新目标，例如 20–30 Hz，并持续递增 `seq`。不要把大量未来目标作为队列一次性下发。

## Arduino 返回的数据

任务事件：

```text
ACK 142
STARTED 142
COMPLETED 142
```

实时目标：

```text
ACK_TARGET 503
IGNORED_TARGET 502
```

周期状态（仅在 `TELEMETRY ON` 后输出）：

```text
STATE <telemetry_seq> <mode> <active_id> <actual_x> <actual_y> <target_x> <target_y>
```

其中 `actual_x/y` 是根据步进脉冲计算的机构位置估计，不是摄像机观察到的棋子位置。

输入/故障状态只在 `STATUS` 或启动时额外输出：

```text
IO X_LIMIT=0 Y_LIMIT=0 MOTORS=1 WATCHDOG=ON REFERENCED=1 SERVO=OFF FAULT=NONE
```

错误统一为：

```text
ERROR <code> <related_id>
```

## 首次正式回零流程

1. 首次上传前先让滑块处于两个方向的中间区域，并卸下可能造成碰撞的舵机连杆或负载。
2. 上传后先发送 `CONFIG`，逐项核对回零方向、行程和步数换算。
3. 手放在电源开关旁，发送 `HOME`。滑块必须先向 X 限位移动，然后退回并慢速二次触发；随后对 Y 重复。
4. 任何方向错误立刻发送 `!` 或切断电机电源，修改对应配置后重新上传。
5. 回零成功后先测试中心附近的小范围任务，例如：

```text
MOVE_TO 1 10 10 2
MOVE_TO 2 20 10 2
MOVE_TO 3 20 20 2
MOVE_TO 4 10 20 2
```

坐标必须位于软限位范围内。当前 X 有效目标是 2–296 mm，Y 有效目标是 2–464 mm。不要在低速、小范围任务没有重复通过之前提高速度。

## 当前边界

- 这是开环步进控制：没有编码器，不会直接知道皮带打滑、堵转或丢步。
- 两个开关按 X、Y 各一个回零开关设计；如果实物是其他拓扑，需要修改回零状态机。
- `STOP` 是软件减速，不是物理急停；真实急停仍应能切断危险输出。
- 舵机仍使用通用角度接口，但固件已按当前机构把可接受范围锁定为 81–118 度；吸附/释放语义由上位机配置映射为 81/118 度。
