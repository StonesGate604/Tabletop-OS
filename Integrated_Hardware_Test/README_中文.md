# Arduino 全硬件联合测试

这个程序用于依次检查：两个限位开关、一个普通位置舵机、两个 A4988 步进驱动和 CoreXY 机构。它不会在上电后自动运动；所有动作都需要从串口监视器手动发送命令。

## 默认接线

程序沿用本项目现有的 Arduino UNO R3 + CNC Shield V3 引脚：

| 部件 | Arduino 引脚 / Shield 位置 |
|---|---|
| 电机 A STEP / DIR | D2 / D5，X 驱动插槽 |
| 电机 B STEP / DIR | D3 / D6，Y 驱动插槽 |
| 步进驱动公共 EN | D8，低电平使能 |
| X 限位 | D9，开关 COM 接 GND、NO 接信号 |
| Y 限位 | D10，开关 COM 接 GND、NO 接信号 |
| 舵机信号 | D11 |

默认按裸机械微动开关的 **COM + NO（常开）** 接法配置，使用 Arduino 内部上拉。如果接的是 COM + NC（常闭），把代码顶部的 `SWITCH_NORMALLY_CLOSED` 改成 `true`。

舵机红线必须接符合舵机额定电压和电流要求的独立稳压电源，舵机电源负极必须与 Shield GND 共地。不能把舵机接到 12 V/24 V 电机电源。首次测试前应拆下舵机连杆或让机构处于不会碰撞的位置。

## 安全行为

- 上电时步进驱动为禁用状态，舵机没有控制脉冲。
- 任一限位开关触发时，程序会禁用全部步进驱动，并停止舵机信号。
- 串口输入单个 `!`，或输入 `STOP` 后回车，会执行相同的全部停止。
- 舵机命令 10 秒后自动停止脉冲；这不会切断舵机电源，也不保证舵机完全失去保持力。
- `DISABLE`、限位停止或紧急停止后，位置参考会被清除，必须重新 `ENABLE`、确认机构位置，再 `ZERO`。
- 软件位置只由步进脉冲推算，没有编码器反馈，不能替代物理急停和人工观察。

## 上传与串口设置

1. 断开电源，核对 A4988 朝向、细分跳帽、电机线圈配对、驱动限流、限位接线、舵机电压以及所有地线。
2. 用 Arduino IDE 打开 `Integrated_Hardware_Test.ino`，选择 Arduino Uno 和对应端口，点击“验证”并上传。
3. 打开串口监视器，选择 **115200 波特率**，行尾选择“换行”。命令必须大写。
4. 把 CoreXY 滑块放在行程中间，首次运动时随时准备切断电机电源。

## 建议测试顺序

### 1. 两个限位开关

启动后应看到两个限位均为 `RELEASED`。分别按下和松开两个开关，应各自显示：

```text
X LIMIT: PRESSED
X LIMIT: RELEASED
Y LIMIT: PRESSED
Y LIMIT: RELEASED
```

也可以输入：

```text
STATUS
```

如果状态相反，检查 NO/NC 接法和 `SWITCH_NORMALLY_CLOSED` 配置。若一直不变化，应先断电排查接线，不要继续电机测试。

### 2. 舵机

先拆下连杆，逐条发送并等待舵机停止：

```text
SERVO 90
SERVO 60
SERVO 120
SERVO 90
OFF
```

确认中位附近运动正常后才逐渐扩大角度。程序接受 `SERVO 0` 到 `SERVO 180`，也接受 `US 500` 到 `US 2500`。如果舵机顶死、持续嗡鸣或电源明显压降，应立即断开舵机电源并缩小角度范围。连续旋转舵机不适用这组角度测试。

### 3. 分别测试两个步进电机

保持 CoreXY 滑块在中间，先使用很少的脉冲：

```text
ENABLE
MOTOR A 100 300
MOTOR A -100 300
MOTOR B 100 300
MOTOR B -100 300
DISABLE
```

`MOTOR` 的最后一个数字是每秒步数。程序限制为每次最多 1600 步、50–800 步/秒。CoreXY 中只转一个电机会让滑块沿斜线移动，这是正常现象；正负方向只用于确认能够反转。某个电机只响不转时，应检查线圈配对、驱动限流、供电、跳帽和机械阻力，不要直接提高速度。

### 4. 测试 CoreXY 的 X/Y 点动

把滑块重新放到安全的中间位置，然后发送：

```text
ENABLE
ZERO
JOG 2 0 2
JOG -2 0 2
JOG 0 2 2
JOG 0 -2 2
STATUS
DISABLE
```

`ZERO` 只把当前位置设为测试原点，不会自动找限位。`JOG` 的参数是相对 X 毫米、相对 Y 毫米和速度（毫米/秒）。每条命令的单轴移动限制为 10 mm，默认测试范围是手动原点周围 ±50 mm，速度限制为 0.2–10 mm/s。

如果 X/Y 方向不对，可修改 `INVERT_A`、`INVERT_B`，一次只改一个并重新测试。如果纯 X 命令走成纯 Y、斜线或卡住，应检查 A/B 电机顺序、皮带绕法及方向配置。不要在方向未确认时增大距离。

代码中的 `STEPS_PER_MM` 默认按 200 整步/圈、1/16 细分、GT2 皮带和 20 齿同步轮计算，即 80 步/mm。三个细分跳帽的实际状态必须与这个参数一致。

## 命令表

| 命令 | 作用 |
|---|---|
| `STATUS` | 显示限位、步进驱动、步数、估算位置和舵机状态 |
| `HELP` | 显示命令提示 |
| `SERVO angle` | 舵机角度命令，0–180 |
| `US pulse` | 直接给舵机脉宽，500–2500 微秒 |
| `OFF` | 停止舵机控制脉冲 |
| `ENABLE` / `DISABLE` | 使能 / 禁用两个步进驱动 |
| `ZERO` | 把当前位置设为 CoreXY 测试原点 |
| `MOTOR A\|B steps rate` | 单独测试 A 或 B 电机；步数可为正或负 |
| `JOG dx dy speed` | CoreXY 相对点动，单位 mm 和 mm/s |
| `STOP` 或 `!` | 禁用步进驱动并停止舵机信号 |

运动期间除 `!` 外的串口输入会被丢弃，不会排队。`!` 停止后请再发送一次换行，然后重新建立安全状态。
