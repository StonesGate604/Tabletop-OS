# 两个限位开关 + 舵机独立测试

适用：Arduino UNO R3 + 常见 CNC Shield V3、两个裸机械微动开关、普通位置舵机。上传此程序会替换板上的电机固件；原 CoreXY_Controller 源文件保留，可随时重新上传。

## 接线（断开 USB 和各路电源后操作）

| 部件 | 连接 |
|---|---|
| X 开关 COM / NO | GND / D9（常见 V3 的 X+ 或 X- 信号针） |
| Y 开关 COM / NO | GND / D10（常见 V3 的 Y+ 或 Y- 信号针） |
| 舵机黄色信号线 | D11（常见 V3.00 的 Z+ 或 Z- 信号针，必须核对实物版本） |
| 舵机红线 | 符合型号额定电压的外部稳压电源正极 |
| 舵机棕线 | 外部电源负极，再将此负极连接 Shield GND |

X+/X- 同轴共用输入，Y+/Y- 同理；正负标记不是供电极性。不能把舵机三针插头直接插到限位排针上，需要拆分引线。不要把舵机接到 12V/24V 电机电源。带电路板的开关模块需要另核对 S/V/G，不套用裸开关接法。

默认开关接 COM + NO（常开）。如果实际使用 COM + NC（常闭），将 `SWITCH_NORMALLY_CLOSED` 改为 `true`。此程序使用内部上拉。

## 上传

1. Arduino IDE 打开同文件夹中的 `Limit_Servo_Test.ino`。
2. 选择 Arduino Uno 和实际串口。如提示缺少 `Servo.h`，在库管理器安装官方 Arduino Servo 库。
3. 首次测试先卸下舵机与机构之间的连杆，避免未知初始角度带动机构。普通连续旋转舵机的指令含义是速度，不适用本程序的角度测试。
4. 上传后打开串口监视器：115200 波特率，行尾选择换行。命令使用大写。

## 先测限位

启动应显示 `X: RELEASED`、`Y: RELEASED`。分别按下开关：对应轴打印 `PRESSED`，松开打印 `RELEASED`。程序有 25 ms 消抖，只在状态变化时打印。

输入 `STATUS` 可查看两个开关的当前状态。若状态相反，检查 NO/NC 接法和配置；一直显示按下或松开时，先断电检查接线。

## 再测舵机

逐条输入并观察，每条之间等舵机停止：

```text
SERVO 90
SERVO 60
SERVO 120
SERVO 90
OFF
```

程序现在接受 `SERVO 0` 到 `SERVO 180`，以 500–2500 微秒对应名义 0–180 度；90 对应 1500 微秒。实际角度依购买版本而定，输出不是位置反馈。首次启动可能从任意当前位置转向中位。

先空载测试上面的 60/120，再逐步扩大到 `SERVO 30`、`SERVO 150`。只有确认机构和舵机行程允许时，才测试 0/180 端点；若出现顶死或持续嗡鸣，断开舵机电源，不要继续向该方向扩大范围。

也可以直接输入 `US 1500`、`US 1200`、`US 1800`，支持 500–2500 微秒整数。SERVO 和 US 控制同一个输出；每次回显实际命令脉宽，`STATUS` 也显示脉宽。例如 `SERVO 60` 输出 1166 微秒，`SERVO 120` 输出 1833 微秒。逐条发送，间隔约 2 秒；无自动往返动作。

- 上电不主动输出舵机脉冲，收到 `SERVO` 或 `US` 才启动；舵机本身仍可能在通电时抖动。
- `OFF` 或即时字符 `!` 停止脉冲输出，不切断舵机电源，也不保证立即机械停止或释放力矩。发送 `!` 后发送一次换行，再输入后续命令。
- 10 秒未收到新的有效 `SERVO` 或 `US` 命令会自动停止脉冲输出。
- 程序运行期间保持 D8 为高，禁用步进驱动，不发送电机运动指令。独立测试时可保持电机电源关闭。
- 限位仅用于显示检测状态，不联动舵机；本程序没有自动回零。

通过标准：两个开关可独立正确显示按下/松开；舵机能响应中位附近的两侧指令，无机构顶死或持续嗡鸣。随后再根据机械安装确定抬起/放下角度，整合电机与自动回零。
